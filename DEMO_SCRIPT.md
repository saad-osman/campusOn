# Demo Script

Full 3-minute walkthrough (finalized in Phase 8, once every feature below is built):

1. Login as `student@demo.com` / `demo1234`.
2. Dashboard: "Continue where you left off" card resumes the last session.
3. Upload a CV in the onboarding/profile wizard.
4. See eligibility verdicts on opportunity cards (eligible / partially eligible / not eligible).
5. Natural-language search: "funded summer AI internships in Europe for 3rd year undergrads".
6. Professor & lab finder for a matched opportunity.
7. Generate an application kit (checklist + SOP + cold email) into a shared Application File.
8. Switch to `teammate@demo.com` — see the generated documents and activity log update.
9. Trigger a change alert (deadline change) on a saved opportunity.
10. Admin analytics dashboard (`admin@demo.com`) — charts, headline stats, CSV export.
11. Embeddable widget rendering on the mock `/demo/portal` page.
